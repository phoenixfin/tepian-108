# Seni dan Aset Visual

Tempat untuk ilustrasi tokoh, lanskap simpul, dan aset visual lain dunia Tepian 108. Siapa saja boleh menyumbang, dan satu tokoh atau simpul boleh punya banyak versi dari banyak seniman.

## Yang dicari

| Jenis | Contoh | Folder |
|---|---|---|
| Potret tokoh | Wajah, setengah badan, atau seluruh badan satu dari 108 bintang. Boleh beberapa gaya | `potret/` |
| Lanskap dan simpul | Suasana pabrik Cakung, tongkang di Barito, pelabuhan Belawan, tanah adat Merauke | `simpul/` |
| Adegan | Ilustrasi satu momen dari plot atau dari cerita kontributor | `adegan/` |
| Aset game | Sprite, tileset, latar, ikon, kotak dialog, antarmuka | `aset/` |
| Identitas | Logo, tipografi, palet, poster, ilustrasi sampul | `identitas/` |
| Peta | Peta simpul, peta rute markas, peta Indonesia 2030 | `peta/` |

Gaya belum ditentukan. Usulan awal: 2D, ilustrasi tangan, palet malam sungai (lihat landing page). Gaya lain sangat disambut, tandai saja sebagai usulan gaya.

## Aturan

- Karya sendiri. Dilisensikan [CC BY-SA 4.0](../LICENSE-CONTENT), sama dengan konten lain.
- Tidak memakai aset, karakter, atau gambar dari Suikoden atau game dan karya lain yang berhak cipta. Referensi gaya boleh, menyalin tidak.
- Foto atau rujukan pihak ketiga harus berlisensi bebas dan dicantumkan sumbernya. Tidak memakai foto orang nyata sebagai wajah tokoh tanpa izin tertulis.
- Bila memakai alat AI generatif, sebutkan di catatan. Kurator menentukan apakah karya itu bisa masuk kanon luas.
- Beri catatan sumber rujukan (daerah, pakaian, bahasa) agar penulis cerita bisa memakainya.

## Cara menyumbang

1. Pilih tokoh, simpul, atau segmen, lalu buka issue "Ikut berkarya" dan pilih jalur Ilustrasi atau Aset visual. Penyumbang lain di tokoh yang sama akan melihatnya.
2. Simpan file di folder yang sesuai. Nama file: `NNN-nama-tokoh-penyumbang-v1.png` untuk tokoh, `slug-simpul-penyumbang-v1.png` untuk simpul.
3. Format: PNG atau WebP untuk gambar jadi, ditambah file sumber (PSD, KRA, SVG, atau Aseprite) bila bisa. Ukuran sisi terpanjang minimal 1600 px untuk ilustrasi. Beri kolom kecil di file `.md` pendamping: judul, alat, rujukan, catatan.
4. Tautkan karyamu di bagian "Visual dan audio" pada file tokoh atau simpul, lalu kirim pull request. Belum terbiasa dengan Git? Kirim lewat issue atau grup komunitas, kurator membantu memasukkannya.
5. Kurator memeriksa kecocokan dengan kanon (misalnya usia, pakaian, asal daerah, nasib tokoh) dan kode etik.

Satu tokoh bisa punya beberapa versi. Versi yang dipakai di game atau sampul dipilih bersama kurator dan penyumbangnya.
