108 bintang

Tiga puluh enam bintang langit dan tujuh puluh dua bintang bumi. Setiap bintang adalah satu orang. Yang masih menunggu penulis bisa kamu adopsi.

Mengadopsi bintang berarti menjadi penanggung jawab kisah, suara, dan riset satu tokoh. Pilih tokoh untuk melihat detailnya.

Cara mengadopsi

  1. Pilih bintang berstatus "Menunggu penulis" di atas.
  2. Ajukan adopsi lewat tombol di detail bintang. Formulir issue GitHub akan terbuka.
  3. Setelah dikonfirmasi kurator, tulis latar, suara, adegan, dan riset tokohmu di file bintangnya.
  4. Kurator meninjau kecocokan dengan kanon. Setelah lolos, tulisanmu menjadi bagian resmi semesta.
