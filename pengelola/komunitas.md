# Struktur Komunitas

Usulan struktur untuk grup obrolan (Discord, atau topik di Telegram). Sesuaikan dengan platform yang kamu pilih.

## Channel

| Channel | Untuk apa |
|---|---|
| #selamat-datang | Pesan sambutan, aturan, dan tautan utama (hanya pengelola yang menulis) |
| #kenalan | Perkenalan: nama atau nama samaran, daerah, dan ingin ikut lewat apa |
| #pengumuman | Kabar proyek dan tantangan pekan ini |
| #usul-nama | Mengusulkan dan membahas nama tokoh terbuka |
| #segmen-a-utama … #segmen-f-bisnis | Satu channel per segmen, untuk koordinasi penggarap |
| #simpul | Riset dan tulisan daerah |
| #visual | Ilustrasi, desain, dan aset |
| #musik-dan-suara | Musik, ambient, dan rekaman suara |
| #game | Desain sistem, kode, dan uji main |
| #karya | Pamer karya yang selesai |
| #bantuan | Pertanyaan dan kesulitan teknis (Git, format file) |
| #santai | Ngobrol di luar topik |

## Pesan sambutan

> Selamat datang di Tepian 108.
>
> Ini proyek terbuka untuk membangun satu semesta cerita dan game bersama, terinspirasi 108 pendekar dan game seperti Suikoden. Latarnya Indonesia, 2030. Belum jadi, dan itu sengaja: namanya, ceritanya, dan banyak hal lain masih menunggu kamu.
>
> **Mulai dari mana?**
> 1. Kenalan di #kenalan (nama samaran boleh): daerahmu, dan kamu ingin ikut lewat apa.
> 2. Lihat tugas kecil di Tugas pemula: http://phx.my.id/tepian-108/mulai.html
> 3. Pilih segmen, simpul, atau tokoh, lalu umumkan bagian yang kamu garap di channel segmennya.
>
> **Yang terkunci:** plot utama, peta simpul besar, dan 23 tokoh inti. **Yang terbuka:** nama 85 tokoh, latar, suara, adegan, dan hampir semua yang lain.
>
> Aturan singkat: tidak ada nama orang atau lembaga nyata, tidak ada ujaran kebencian, kekerasan ditulis untuk menunjukkan akibatnya, dan karya sendiri. Aturan lengkap: http://phx.my.id/tepian-108/tata-kelola.html

## Aturan grup

1. Hormati sesama. Beda pendapat soal cerita boleh, merendahkan orang tidak.
2. Ikuti [kode etik](../CODE_OF_CONDUCT.md) dan [aturan main](http://phx.my.id/tepian-108/dunia.html#aturan).
3. Jangan menyebarkan karya orang lain tanpa izin.
4. Tidak ada promosi di luar topik tanpa izin pengelola.
5. Laporkan pelanggaran ke pengelola lewat pesan pribadi. Pelapor dijaga identitasnya.
